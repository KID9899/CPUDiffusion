# Инструкция по работе с библиотеками

## Общая схема

Сборка всех библиотек унифицирована с помощью функции `add_dynamic_library` из файла `BuildLibrary.cmake`.  
Каждая библиотека представляет собой отдельную динамическую библиотеку (`.so`), а её публичные заголовки автоматически копируются в `lib/includes/<имя_библиотеки>/`.

## Добавление новой библиотеки

1. Создайте папку `lib/src/<имя_библиотеки>`.
2. Внутри неё или внутри её поддиректорий разместите исходные файлы (`.cpp`) и заголовки (`.h`).
3. Создайте в этой же папке `CMakeLists.txt` со следующим содержимым:

```cmake
add_dynamic_library(
    NAME <имя_библиотеки>   # Обязательно должно совпадать с именем папки
    SOURCES
        # Список исходников относительно папки библиотеки (lib/src/<имя_библиотеки>)
        file1.cpp
        subdir/file2.cpp
        subdir/subsubdir/file3.cpp
        ...
    HEADERS
        # список публичных заголовков относительно папки библиотеки (эти заголовки будут скопированы и доступны пользователю)
        some_header1.h
        subdir/some_header2.h
        subdir/subsubdir/some_header3.cpp
        ...
    COMPILE_FLAGS    # дополнительные флаги компилятора (необязательно)
        -Isome/path
    LINK_LIBRARIES   # флаги линковки (необязательно)
        -fopenmp     # например
)

# Обязательно написать эти две строчки, иначе компиляция не пройдёт
set(LIB_TARGET  ${LIB_TARGET}  PARENT_SCOPE)
set(COPY_TARGET ${COPY_TARGET} PARENT_SCOPE)
```

После этого библиотека **автоматически** будет обнаружена и подключена к основной программе – редактировать корневой `CMakeLists.txt` не требуется.

## Подключение заголовков в коде

### Внутри самой библиотеки (в её исходниках)
Можно использовать два варианта включаемых путей:
```cpp
#include "some_header.h"                                 // если файл лежит в той же поддиректории
#include "<название_библиотеки>/subdir/some_header.h"    // относительно lib/src (рекомендуется в остальных случаях)
```

### В основной программе или в других библиотеках
Используйте путь относительно `lib/includes`:
```cpp
#include "<название_библиотеки>/some_header.h"
#include "<название_библиотеки>/subdir/some_header.h"
```

## Сборка и зависимости

Основная программа автоматически линкуется со всеми библиотеками, найденными в `lib/src`.  
Зависимость от копирования заголовков также выстроена – перед компиляцией `main.cpp` все заголовки будут актуальны.

## Примечания

- Если исходников нет (только заголовки), оставьте `SOURCES` пустым. Библиотека не будет собираться, но заголовки всё равно скопируются, и фиктивная цель будет создана, чтобы не нарушить граф зависимостей.
- Для добавления нестандартных флагов компиляции или линковки используйте `COMPILE_FLAGS` и `LINK_LIBRARIES` соответственно.
